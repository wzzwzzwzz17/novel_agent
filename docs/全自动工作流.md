# NovelAgent 全自动工作流

参考 SillyTavern Prompt 组装顺序 + Smart-Memory「写后提取」范式。

## 单轮固定流水线（`auto=true`，默认）

1. **Plan**：AUX API 从指令抽取 NovelRef 关键词 + 场景词（失败则启发式）
2. **Reference**：双站并行抓取 → 交错合并 → **DeepSeek API L3 合格判定** → 注入参考区（永不写入正文）
3. **Compose**：系统约束 → 总纲 → 全局摘要 → 压缩摘要 → 角色卡 → 召回记忆 → 参考 → 近期对话 → 用户指令
4. **Generate**：主模型续写
5. **Post**：清洗元文本；OOC 黄灯提示（不改写正文）
6. **Memory**：事件提取 → 更新全局摘要 → 滑动窗口压缩

失败降级：参考 empty/error、记忆提取失败均不阻断正文。

## 代理

`NOVELREF_PROXY=auto`：先直连，再试环境变量代理与常见本地端口（7890/7897/10809…）。

## API

- `POST /api/sessions/{id}/write` `{ "instruction": "...", "auto": true }`
- `POST /api/sessions/{id}/auto-write` 同上
- `POST /api/novelref/probe` 双站强制 + 审稿探测
