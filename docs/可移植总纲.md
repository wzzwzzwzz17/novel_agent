# NovelAgent 可移植总纲（本地量化 / 云端仅 API）

> 依据三份参考文档综合修订。原 NovelAgent 总纲「不做云端」由本版覆盖：**必须可移植到云服务器**；云端**只做 API 调用**，不部署本地量化模型。

## 1. 一句话定位

可移植的小说创作 Agent：**会话隔离 + 角色卡 + 三层记忆 + NovelRef 风格参考 + 统一模型路由**。  
同一套代码在本地跑「量化模型 + API 辅助」，在云端跑「纯 OpenAI 兼容 API」。

## 2. 相对原文档的硬性修订

| 原文档约定 | 本版 |
|---|---|
| 仅桌面、不提供云端 | **FastAPI 同构服务**；本地 / 云端同一入口 |
| 本地 GGUF 必选 | **可选**：`DEPLOY_PROFILE=local` 才加载量化；`cloud` **完全跳过**本地推理代码路径 |
| Electron/PyQt 桌面优先 | P0 先 **Web UI + API**（易移植）；桌面壳可后挂 |
| NovelRef 单站 alicesw | 采用**双站点适配版**（关键词检索，非标签页） |
| DeepSeek 写死 | **OpenAI 兼容**适配器（DeepSeek / 自建 vLLM / 云厂商均可） |

## 3. 部署画像

```
本地 (DEPLOY_PROFILE=local)
  ├─ 正文续写 → 本地量化（llama.cpp / OpenAI 兼容本地端点，如 :8001）
  ├─ 摘要 / 角色优化 / NovelRef L3 → 远程 API（可关）
  └─ 数据 → $NOVELAGENT_HOME/data

云端 (DEPLOY_PROFILE=cloud)
  ├─ 全部推理 → 仅 API（OPENAI_BASE_URL + API_KEY）
  ├─ 不加载、不检测、不依赖任何本地权重 / CUDA / llama-cpp
  └─ 数据 → 挂载卷或对象存储路径（仍用同一 Session JSON 布局）
```

环境变量（移植核心，禁止写死绝对路径）：

- `NOVELAGENT_HOME`：数据与配置根（默认 `./.novelagent`）
- `DEPLOY_PROFILE`：`local` | `cloud`
- `LLM_PRIMARY_BASE_URL` / `LLM_PRIMARY_API_KEY` / `LLM_PRIMARY_MODEL`
- `LLM_AUX_BASE_URL` / `LLM_AUX_API_KEY` / `LLM_AUX_MODEL`（辅助任务；可空=复用 primary）
- `LOCAL_LLM_ENABLED`：仅 local 画像为 true；cloud 强制 false
- `NOVELREF_ENABLED`：是否启用参考 Skill

## 5. 模块优先级（与原 P0–P4 对齐，按可移植重排）

| 阶段 | 内容 | 验收 |
|---|---|---|
| **P0** | 配置/路径抽象、Session 隔离、Prompt 组装、API Provider、FastAPI 续写、NovelRef 骨架 | 云端 `.env` 仅填 API 即可续写；本地可指向量化服务 URL |
| **P1** | 角色卡 + 一键优化（走 AUX API） | 人设注入续写可见 |
| **P2** | NovelRef 双站完整链路 + 工具日志 | empty/error 不阻塞；正文与参考隔离 |
| **P3** | 三层记忆 | 长轮次保留关键事件 |
| **P4** | 导入导出、OOC 提示、UI 打磨 | 会话可备份迁移 |

## 6. 模型路由（ModelRouter）

- `local_first`：正文 → local/primary；辅助 → aux（API）
- `local_only`：全部 primary（本地端点）；无 aux 时关闭优化/L3
- `api_first` / `api_only`：全部走 API（**云端默认 api_only**）

本地量化：**不内嵌加载权重**。本地也通过「OpenAI 兼容 HTTP」（如已有 `:8001`）接入，这样：
1. 与云端代码路径一致；
2. 量化服务（Unsloth/llama.cpp/vLLM）可独立进程，Agent 无 CUDA 耦合；
3. 移植云端时删除 local URL 即可，零改代码。

## 7. NovelRef 契约（上层硬约束）

- 接口：`list_tags()` / `get_reference(keyword, scene_keywords, max_paragraphs)`
- 单次创作 ≤2 次调用；参考只进 Prompt 参考区，永不拼进正文
- 正文仅内存；empty/error 静默继续

## 8. 合规红线（继承）

不落盘抓取原文；robots + 限流 + 熔断；会话严格隔离；本项目不做模型微调。
